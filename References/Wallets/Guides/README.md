# Older MetaMask send references

Retrieved 13 October 2026 from the [localized first-party MetaMask send guide](https://support.metamask.io/fr/manage-crypto/move-crypto/send/how-to-send-tokens-from-your-metamask-wallet). The three PNGs preserve the unchanged downloaded bytes for recipient entry, amount entry, and gas-fee confirmation. `sources.json` records their exact public IPFS URLs, byte counts, SHA-256 hashes, format/dimensions, and provenance limits.

These screenshots use an older white and blue design. They are **research only** and are not implemented as the current dark-style UI. The saved App Store baseline shows a different visual design; the current [English send guide](https://support.metamask.io/manage-crypto/move-crypto/send/how-to-send-tokens-from-your-metamask-wallet) also describes amount before recipient, whereas these localized screenshots show recipient before amount. Neither page supplies the images' capture version or date.

Do not silently combine these older screenshots with the dark baseline or treat them as current-version proof. A separate older visual preset would need an explicitly selected reference baseline and its own matching-state checks.

These files are research references and are not bundled application assets. No open license or redistribution permission is inferred from their public availability.
