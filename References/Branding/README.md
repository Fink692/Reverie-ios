# Brand variant icon provenance

Retrieved 2026-10-13. These 13 app-icon assets use the actual artwork published by each app's seller through Apple's App Store, rather than redrawn or generated logos.

Each source came from `artworkUrl512` in the saved Apple lookup result in `References/Banks/<rawid>.json` or `References/Shopify/itunes-lookup-2026-10-13.json`. The last rendition path was changed from `/512x512bb.jpg` to `/1024x1024bb.png` to request Apple's 1024-pixel PNG output. All download URLs and final response URLs were required to use HTTPS and the exact `mzstatic.com` domain or one of its subdomains before being accepted.

All downloaded images decode as **PNG, 1024 × 1024, opaque RGB**. Their original bytes were copied directly into `Sources/Assets.xcassets/Brand-<rawid>.appiconset/AppIcon.png`. No cropping, recoloring, compositing, logo redrawing, or visible-pixel changes were performed. `artwork-sources.json` records exact public artwork URLs, source listing/seller information, file paths, and both download and asset SHA-256 hashes. Every download hash equals its corresponding app asset hash.

`inspection-contact-sheet.png` is an inspection aid containing thumbnails of all 13 unchanged originals. It was visually inspected, along with full-size Shopify and Chase artwork. It is not an application asset.

`variants.json` is the build metadata array. It uses `id`, `displayName`, `bundleIdentifier`, `appIcon`, `playbackKind`, and, for bank variants, `bankTheme`. All bundle identifiers are unique under `com.reverie.brand.*`. The selected display names are brand names. The App Store listing title is recorded separately, and **the genuine apps' installed CFBundleDisplayName values were not verified**. These metadata labels should not be described as verified exact installed app names.
